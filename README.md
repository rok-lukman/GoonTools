# GoonTools
The official Goon Squad addon

# Features
- Makes a screenshot when you level up!
- Automagically accepts party/raid invites (optionally only from guild members).
- Invites people who whisper a keyword (`inv` or `invite`), optionally guild members only.
- Welcomes new guild members and congratulates them when they reach the next level!
  By default only capstone levels (10, 20, 30, ...) are announced; toggle "Capstone levels only" in /gt.
  Only one GoonTools user in the guild (the online user with the lowest GUID) posts these, so they aren't repeated.

# Slash commands
- /gt	Open GoonTools Configuration!
- /gt names, /gt levels [name], /gt peers	Debug output (online members, levels, other GoonTools users).
- /ffa	Set loot to Free For All (group leader only).
- /gl	Set loot to Group Loot (group leader only).
- /pl	Leave the current party.
